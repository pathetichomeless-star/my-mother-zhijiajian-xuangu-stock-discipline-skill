# 匿名案例 · 周期品（大宗商品）底部反转交易事件（投资流程透镜分析）

以一起虚构的、完全匿名化的周期品底部反转交易为素材，演示同一套“标的生命周期”结构如何迁移到“非股权、非人物”的纯供需周期标的。所有主体一律化名，不对应任何真实品种、公司及自然人。

> 本分析仅提炼决策结构，不评判事件真伪或道德。案例如涉真实人物，应匿名化并加 disclaimer。

## 六阶段生命周期映射

| 阶段 | 事件节点 | 股市映射 | 纪律 |
|------|----------|----------|------|
| 1. 冷门期锁定标的 | 交易者 A 在商品价格处于底部、叙事一片悲观时即研究并建立认知头寸，跟踪供需拐点（产能、库存、开工率），而非在牛市高潮才追。 | 在标的无人问津时建立认知头寸——冷门期发现、长期跟踪，避免在高潮期后知后觉。 | 区分“我认同的宏观叙事”与“我验证过的库存/开工数据”；底部研究不是信仰，是可证伪的拐点假设。 |
| 2. 被竞品/旧庄占据 | 底部阶段，旧高成本产能 C 仍在场、旧库存压制价格；A 无法直接干净做多，只能等其出清。 | 标的被旧产能/旧库存“占据”，只能场外等待出清。 | 来晚了不硬挤；先判断“供给出清的卡点”而非在压制未解除时强行建仓。 |
| 3. 解绑（带隐性负债） | C 高成本产能减产/破产退出，价格松动；但遗留债务、环保或地缘尾部风险仍在，供给出清真实性待验。 | 旧产能退出——旧“庄”走了，伤口还在。 | 解绑 ≠ 干净，更 ≠ 可买；先验证供给出清是否真实（而非预期），用尽调而非听故事。 |
| 4. 首次接触/试水 | A 以小幅敞口（期货/ETF/相关股票）首次真实下注，核对库存与开工数据是否兑现拐点 thesis（祛魅）。 | 认知头寸 → 真实头寸，长期看多者往往建仓即发现数据落差。 | 用真金小仓验证 thesis，别用多年宏观信仰下重注；设可证伪假设与 kill switch。 |
| 5. 重仓 + 尾部闸门 | 供需确认反转、价格突破后 A 追加；但预先约定“若 C 复产或地缘缓和致回撤则一票否决”，闸门由独立规则触发。 | 主升浪加仓 = 大钱；尾部风险（供给回摆）交独立规则做一票否决。 | 闸门要用在每一笔大钱，不是只在最后一步；独立仲裁者的目标函数必须与“我想加仓”不同。 |
| 6. 退出维权/公开叙事 | 价格进入过热、叙事一面倒看多时 A 分批减仓；分清“止盈”与“对 B（周期本身）的持仓叙事管理”两件事。 | 减仓 = 平仓；公开唱多/唱空是持仓叙事而非事实。 | 退出分清“止盈”与“叙事”；公开叙事有反身性反噬风险，别把营销当基本面。 |

## 建仓决策 Checklist

| 阶段 | 检查项 | 一票否决条件 | 证据来源 |
|------|--------|--------------|----------|
| 尽调 | 是否独立、可证伪？是否调查了激励结构？ | 研究不能证伪 thesis / 未识别对方动机 | 财报、产业链、激励方披露 |
| 试水 | 是否小仓试探？有无可证伪假设？ | 无 kill switch / 假设不可证伪 | 模拟仓 / 极小仓实盘反馈 |
| 风险闸门 | 谁/什么规则有否决权？目标函数是否独立？ | 无独立仲裁者 / 规则未在冷静时写下 | 预先承诺的纪律文档 |
| 仓位 | 是否基于最坏情况回撤？ | 单一不利结果可致命 | 尾部情景测算 |
| 可逆性 | 仓位 size 是否与可逆性成正比？ | 不可逆仓位过大 | 流动性 / 锁定期评估 |
| 分账户 | 利润与本金是否分账户？ | “仅退款”心态（既要收益又要本金） | 心理账户记录 |
| 叙事反向 | 利益方长篇叙事：脱节？越界？背书具体诉求？ | 三者任一命中且无对冲 | 叙事 vs 现金流核对 |

## 收敛纪律

- 标的生命周期纪律：锁定（冷门期建认知头寸）→ 等竞品解绑（不硬挤）→ 验残留风险（解绑≠便宜）→ 小仓试水祛魅 → 大钱前置对价必设退出机制 → 尾部加价交给独立闸门 → 退出分清追偿与叙事。
- 闸门前置纪律：风险闸门要用在每一笔大钱（含预付对价），不是只在最后一步。
- 叙事反向纪律：别人（尤其利益方）的公开长篇叙事，先当“诉求信号”而非“事实信号”处理。

## 附记

本样例演示框架适用于“非股权、非人物”的纯周期标的：此处“标的 B”是一段商品供需周期本身，而非公司或自然人。六阶段依然成立，只是载体变了——证明本 skill 的迁移边界是“任何有生命周期的标的”，而非局限于股权类资产。对应 references/lifecycle-mapping.md。
