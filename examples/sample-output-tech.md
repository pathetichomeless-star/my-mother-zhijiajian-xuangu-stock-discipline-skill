# 匿名案例 · 硬科技上市公司（AI 算力设备）建仓事件（投资流程透镜分析）

以一起虚构的、完全匿名化的硬科技二级市场交易为素材，演示同一套“标的生命周期”结构如何迁移到半导体/AI 算力赛道。人物与主体一律化名，不对应任何真实公司或自然人。

> 本分析仅提炼决策结构，不评判事件真伪或道德。案例如涉真实人物，应匿名化并加 disclaimer。

## 六阶段生命周期映射

| 阶段 | 事件节点 | 股市映射 | 纪律 |
|------|----------|----------|------|
| 1. 冷门期锁定标的 | 投资人 A 在 AI 资本寒冬（行业低谷期）即研究并锁定 B 公司的技术路线，建立认知头寸，长期跟踪而非追高。 | 在标的无人问津时建立认知头寸——冷门期发现、长期跟踪，避免在高潮期才后知后觉。 | 区分“我认同的产业叙事”与“我验证过的订单与产能”；低谷期的研究不是信仰，是可证伪的假设。 |
| 2. 被竞品/旧庄占据 | B 的核心团队此前出自大厂研究院 C，关键技术 IP 仍与 C 存在绑定，A 无法直接干净入场。 | 标的处于旧关联方控股/技术依赖期，只能场外等待解绑。 | 来晚了不硬挤；先判断“卡点在哪”，而不是在绑定未解除时强行建仓。 |
| 3. 解绑（带隐性负债） | B 从 C 独立，核心人员离职，但专利归属、竞业限制、训练数据权属仍有残留风险。 | 困境/分拆反转标的——旧庄走了，伤口还在。 | 解绑 ≠ 干净，更 ≠ 可买；先评估残留风险（IP 诉讼、竞业、客户继承），用尽调验证而非听故事。 |
| 4. 首次接触/试水 | A 以极小仓位（或可转债）首次真实下注，实地验证团队执行力与招股/路演故事之间的落差（祛魅）。 | 认知头寸 → 真实头寸，长期关注者往往买入即发现预期差反转。 | 用真金小仓验证 thesis，别用多年产业信仰下重注；设可证伪假设与 kill switch。 |
| 5. 重仓 + 尾部闸门 | B 拿到大客户订单、业绩初步兑现后 A 追加；但预先约定“若 C 发起 IP 诉讼则一票否决”，闸门由规则而非情绪触发。 | 主升浪加仓 = 大钱；尾部风险（IP 诉讼）交独立规则做一票否决。 | 闸门要用在每一笔大钱，不是只在最后一步；独立仲裁者的目标函数必须与“我想加仓”不同。 |
| 6. 退出维权/公开叙事 | B 业绩兑现后 A 分批减仓；若遇 C 追溯 IP，A 分清“向 C 追偿”与“对 B 的持仓叙事管理”两件事。 | 减仓 = 平仓；对 C 追偿 = 法务；公开唱多/唱空 B 是持仓叙事而非事实。 | 退出分清“追偿”与“叙事”；公开叙事有反身性反噬风险，别把营销当基本面。 |

## 建仓决策 Checklist

| 阶段 | 检查项 | 一票否决条件 | 证据来源 |
|------|--------|--------------|----------|
| 尽调 | 是否独立、可证伪？是否调查了激励结构？ | 研究不能证伪 thesis / 未识别对方动机 | 财报、产业链、激励方披露 |
| 试水 | 是否小仓试探？有无可证伪假设？ | 无 kill switch / 假设不可证伪 | 模拟仓 / 极小仓实盘反馈 |
| 风险闸门 | 谁/什么规则有否决权？目标函数是否独立？ | 无独立仲裁者 / 规则未在冷静时写下 | 预先承诺的纪律文档 |
| 仓位 | 是否基于最坏情况回撤？ | 单一不利结果可致命 | 尾部情景测算 |
| 可逆性 | 仓位 size 是否与可逆性成正比？ | 不可逆仓位过大 | 流动性 / 锁定期评估 |
| 分账户 | 利润与本金是否分账户？ | “仅退款”心态（既要收益又要本金） | 心理账户记录 |
| 叙事反向 | 利益方长篇叙事：脱节？越界？背书具体诉求？ | 三者任一命中且无对冲 | 叙事 vs 现金流核对 |

## 收敛纪律

- 标的生命周期纪律：锁定（冷门期建认知头寸）→ 等竞品解绑（不硬挤）→ 验残留风险（解绑≠便宜）→ 小仓试水祛魅 → 大钱前置对价必设退出机制 → 尾部加价交给独立闸门 → 退出分清追偿与叙事。
- 闸门前置纪律：风险闸门要用在每一笔大钱（含预付对价），不是只在最后一步。
- 叙事反向纪律：别人（尤其利益方）的公开长篇叙事，先当“诉求信号”而非“事实信号”处理。
