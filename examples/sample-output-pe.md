# 匿名案例 · 一级市场老股转让（pre-IPO）接盘事件（投资流程透镜分析）

以一起虚构的、完全匿名化的一级市场老股转让交易为素材，演示同一套“标的生命周期”结构如何迁移到非上市股权（private / pre-IPO）资产类别。人物与主体一律化名，不对应任何真实基金、公司及自然人。

> 本分析仅提炼决策结构，不评判事件真伪或道德。案例如涉真实人物，应匿名化并加 disclaimer。

## 六阶段生命周期映射

| 阶段 | 事件节点 | 股市映射 | 纪律 |
|------|----------|----------|------|
| 1. 冷门期锁定标的 | 投资人 A 在一级市场募资寒冬（老股无人接、估值下杀）即尽调并锁定 B 公司的老股转让机会，建立认知头寸，而非在 IPO 预期升温后才追。 | 在标的无人问津时建立认知头寸——一级冷门期发现、长期跟踪，避免在 Pre-IPO 预期最热时接最后一棒。 | 区分“我认可的退出逻辑”与“我验证过的经营数据”；冷门期研究不是信仰，是可证伪的假设。 |
| 2. 被竞品/旧庄占据 | B 的老股集中在上一轮领投方 C（某美元基金）手上，受 SPA 锁定期与优先清算权约束，A 无法直接干净接盘。 | 标的筹码在旧股东/旧“庄”手里，只能等其因基金到期而释放。 | 来晚了不硬挤；先判断“筹码何时释放”与“约束条款是什么”，而非在锁定未解除时强行接。 |
| 3. 解绑（带隐性负债） | C 因基金到期、LP 压力转让份额，但交易附带回售权、对赌、优先清算等隐性负债，且 B 公司章程存在特殊表决安排。 | 老股“解禁”释放——旧股东走了，但对赌/优先权等伤口还在。 | 解绑 ≠ 干净，更 ≠ 便宜；先用条款尽调验证隐性负债（回购义务、优先权顺位），别只看转让价格。 |
| 4. 首次接触/试水 | A 先小比例接一点老股（试水），实地核对公司经营、客户与招股书/路演故事的落差（祛魅）。 | 认知头寸 → 真实头寸，一级市场长期观察者往往尽调后即发现预期差。 | 用真金小仓验证 thesis，别用“pre-IPO 必赚”的信仰下重注；设可证伪假设与 kill switch。 |
| 5. 重仓 + 尾部闸门 | B 启动上市辅导、确定性提升后 A 追加接盘；但预先约定“若对赌触发回购则一票否决”，闸门由独立条款审查（目标函数不同于“我想接盘”）触发。 | IPO 确定性提升后的加仓 = 大钱；尾部风险（对赌回购）交独立规则做一票否决。 | 闸门要用在每一笔大钱，不是只在最后一步；独立仲裁者的目标函数必须与“我想加仓/接盘”不同。 |
| 6. 退出维权/公开叙事 | B 上市后 A 于解禁期分批减仓；若对赌被触发需回购，A 分清“向 C/创始人追偿”与“对 B 的持仓叙事管理”两件事。 | 解禁减仓 = 平仓；向创始人/C 追偿 = 法务；公开唱多/唱空 B 是持仓叙事而非事实。 | 退出分清“追偿”与“叙事”；公开叙事有反身性反噬风险，别把营销当基本面。 |

## 建仓决策 Checklist

| 阶段 | 检查项 | 一票否决条件 | 证据来源 |
|------|--------|--------------|----------|
| 尽调 | 是否独立、可证伪？是否调查了激励结构？ | 研究不能证伪 thesis / 未识别对方动机 | 财报、产业链、激励方披露 |
| 试水 | 是否小仓试探？有无可证伪假设？ | 无 kill switch / 假设不可证伪 | 模拟仓 / 极小仓实盘反馈 |
| 风险闸门 | 谁/什么规则有否决权？目标函数是否独立？ | 无独立仲裁者 / 规则未在冷静时写下 | 预先承诺的纪律文档 |
| 仓位 | 是否基于最坏情况回撤？ | 单一不利结果可致命 | 尾部情景测算 |
| 可逆性 | 仓位 size 是否与可逆性成正比？ | 不可逆仓位过大 | 流动性 / 锁定期评估 |
| 分账户 | 利润与本金是否分账户？ | “仅退款”心态（既要收益又要本金） | 心理账户记录 |
| 叙事反向 | 利益方长篇叙事：脱节？越界？背书具体诉求？ | 三者任一命中且无对冲 | 叙事 vs 现金流核对 |

## 收敛纪律

- 标的生命周期纪律：锁定（冷门期建认知头寸）→ 等竞品解绑（不硬挤）→ 验残留风险（解绑≠便宜）→ 小仓试水祛魅 → 大钱前置对价必设退出机制 → 尾部加价交给独立闸门 → 退出分清追偿与叙事。
- 闸门前置纪律：风险闸门要用在每一笔大钱（含预付对价），不是只在最后一步。
- 叙事反向纪律：别人（尤其利益方）的公开长篇叙事，先当“诉求信号”而非“事实信号”处理。

## 附记

本样例演示框架跨越资产类别：从原案例的私人纠纷叙事、硬科技二级，到此处的非上市老股转让。三者的“解绑期隐性负债”分别表现为声誉负债、IP 风险、对赌/优先权——同一结构、不同载体。对应 references/lifecycle-mapping.md。
