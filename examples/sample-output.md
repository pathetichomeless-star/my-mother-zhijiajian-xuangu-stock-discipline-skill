# 匿名案例 · 高净值人士情感与彩礼诉讼事件（投资流程透镜分析）

以一起公开的、涉诉且被当事人标注“虚构”的私人纠纷网络事件为素材，仅抽取其“标的生命周期”结构映射到股市纪律。人物一律化名，不认定事实。

> 本分析仅提炼决策结构，不评判事件真伪或道德。案例如涉真实人物，应匿名化并加 disclaimer。

## 六阶段生命周期映射

| 阶段 | 事件节点 | 股市映射 | 纪律 |
|------|----------|----------|------|
| 1. 冷门期锁定标的 | 投资人 A 十多年前初见标的 B 的公开宣传照，长期保存于个人设备、视为“白月光”，多年后才真实接触。 | 在标的无人问津时建立认知头寸（cognitive position）——冷门期发现、长期跟踪。 | 区分“我喜欢的故事”与“我理解的公司”；A 存的是包装好的人设照，非真实基本面。 |
| 2. 被竞品/旧庄占据 | B 与旧关联方 C 绑定期间，A 完全无法入场。 | 标的处于他人控股/主升浪，只能场外等待。 | 来晚了不硬挤；A 这步做对了——他等。 |
| 3. 解绑（带隐性负债） | B 与 C 分手，C 风波致 B 声誉受损；标的“自由”但带隐性负债。 | 困境反转标的——旧庄走了，伤口还在。 | 解绑 ≠ 便宜，更 ≠ 可买；先评估残留风险（商誉、诉讼、声誉）。 |
| 4. 首次接触/试水 | A 与 B 首次真实接触，自述“忽然想不起来我等的是什么”（祛魅）。 | 认知头寸 → 真实头寸，长期关注者往往买入即失望（预期差反转）。 | 用真金小仓验证 thesis，别用多年幻想下重注。 |
| 5. 重仓 + 尾部闸门 | 前置对价（彩礼）打入对方账户难收回；尾部加价（5000万），A 把全部现金跑给 AI 评估后拒绝。 | 预付对价 = 沉没成本 + 对手锁定；尾部加价交独立仲裁者做一票否决。 | 闸门要用在每一笔大钱（含前置对价），不是只在最后一步。 |
| 6. 退出维权/公开叙事 | 先发诉讼事实（硬锚），再发长文（软放大），约 17 分钟精确间隔。 | 追偿 = 平仓；长文公开 = 做空报告式舆论施压。 | 退出分清“追偿”与“叙事”；公开细节有反身性反噬风险。 |

## 建仓决策 Checklist

| 阶段 | 检查项 | 一票否决条件 | 证据来源 |
|------|--------|--------------|----------|
| 尽调 | 是否独立、可证伪？是否调查了激励结构？ | 研究不能证伪 thesis / 未识别对方动机 | 财报、产业链、激励方披露 |
| 试水 | 是否小仓试探？有无可证伪假设？ | 无 kill switch / 假设不可证伪 | 模拟仓 / 极小仓实盘反馈 |
| 风险闸门 | 谁/什么规则有否决权？目标函数是否独立？ | 无独立仲裁者 / 规则未在冷静时写下 | 预先承诺的纪律文档 |
| 仓位 | 是否基于最坏情况回撤？ | 单一不利结果可致命 | 尾部情景测算 |
| 可逆性 | 仓位 size 是否与可逆性成正比？ | 不可逆仓位过大 | 流动性 / 锁定期评估 |
| 分账户 | 利润与本金是否分账户？ | “仅退款”心态（既要收益又要本金） | 心理账户记录 |
| 叙事反向 | 利益方长篇叙事：脱节？越界？背书具体诉求？ | 三者任一命中且无对冲 | 叙事 vs 现金流核对 |

## 收敛纪律

- 标的生命周期纪律：锁定（冷门期建认知头寸）→ 等竞品解绑（不硬挤）→ 验残留风险（解绑≠便宜）→ 小仓试水祛魅 → 大钱前置对价必设退出机制 → 尾部加价交给独立闸门 → 退出分清追偿与叙事。
- 闸门前置纪律：风险闸门要用在每一笔大钱（含预付对价），不是只在最后一步。
- 叙事反向纪律：别人（尤其利益方）的公开长篇叙事，先当“诉求信号”而非“事实信号”处理。
