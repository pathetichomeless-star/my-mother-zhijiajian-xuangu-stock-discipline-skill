# 投资流程透镜 · 深度原则与建仓 Checklist

> 本文件为 `invest-decision-lens` 的参考细节。案例均为匿名化改编，仅用于抽象决策结构。

## 八条深层原则（深度展开）

### 1. 信念-资本解耦（Conviction-Capital Decoupling）
大多数人亏钱不是研究不够，而是"信念"与"资本"被自动耦合——一旦看懂/喜欢，仓位就自动放大。流程的价值是在"我喜欢"和"我给钱"之间插入一个**摩擦点（friction）**。你需要的不是更聪明的研究，而是一个在最高 conviction 时强制你停一下的机制。

### 2. 调查激励而非事实（Incentives over Facts）
对"人/标的"的尽调常看事实（财务、赛道、人设），却少问"谁有动机骗我 / 卖给我"。Adverse selection：当有人极度想把你拉进一笔交易，先问"他为什么这么想成交"。真正的尽调对象是**激励结构**，而非漂亮财报。

### 3. 独立仲裁者必须有不同目标函数（Different Objective Function）
你无法给自己当断路器——你会被自己的叙事说服。风险闸门必须是一个目标函数与你"PM 大脑"不同的**人 / 规则 / 模型**。规则须在冷静时写下、狂热时执行（pre-commitment / Ulysses binding）。

### 4. 沉没成本与承诺升级（Escalation of Commitment）
一旦投入，人会"增加"承诺以 justify 先前投入。试水须配"**证伪即退出**"的硬性开关，否则退化为加仓摊平式被套。

### 5. 仓位基于最坏情况而非期望值（Worst-case Sizing）
仓位大小应基于**最坏情况回撤**，不是预期收益。Kelly 思想：永远不要大到"单一不利结果就致命"。高赔率上 all-in 算的是期望、忽略的是尾部。

### 6. 叙事是工具、现金流是地基（Narrative vs Cashflow）
叙事驱动短期价格、基本面驱动长期。大仓位具**反身性（reflexivity）**：你的建仓行为本身改变标的（冲击成本、信号效应）。区分好故事与好生意。

### 7. 尽调剧场鉴别（Due-Diligence Theater）
用忙碌证明早已做出的决定。鉴别：这份研究若得出相反结论，我会改主意吗？若不会，就是剧场。

### 8. 风险不可接受 = 不交易（Risk Rejection ≠ Downsize）
系统性风险不靠仓位大小化解。风险大到不能接受，就**空仓**，而非"小仓试试"。

### 9. 反向解读利益方叙事（Reverse-read Stakeholder Narratives）
当创始人/大股东突然在社交平台发长篇叙事，先当"诉求信号"而非"事实信号"。详见本文档末节。

## 建仓决策 Checklist 模板

| 阶段 | 检查项 | 一票否决条件 | 证据来源 |
|------|--------|--------------|----------|
| 尽调 | 是否独立、可证伪？是否调查了激励结构？ | 研究不能证伪 thesis / 未识别对方动机 | 财报、产业链、激励方披露 |
| 试水 | 是否小仓试探？有无可证伪假设？ | 无 kill switch / 假设不可证伪 | 模拟仓 / 极小仓实盘反馈 |
| 风险闸门 | 谁/什么规则有否决权？目标函数是否独立？ | 无独立仲裁者 / 规则未在冷静时写下 | 预先承诺的纪律文档 |
| 仓位 | 是否基于最坏情况回撤？ | 单一不利结果可致命 | 尾部情景测算 |
| 可逆性 | 仓位 size 是否与可逆性成正比？ | 不可逆仓位过大 | 流动性 / 锁定期评估 |
| 分账户 | 利润与本金是否分账户？ | "仅退款"心态（既要收益又要本金） | 心理账户记录 |
| 叙事反向 | 利益方长篇叙事：脱节？越界？背书具体诉求？ | 三者任一命中且无对冲 | 叙事 vs 现金流核对 |

## 反向解读社交平台叙事（原则 9 的检查表）
当创始人/大股东突然发长篇叙事：
1. **人设维持（credibility arbitrage）**：混发真行业观点 + 定向叙事，用正当性给私人诉求镀金。
2. **"虚构 + 实名"双轨**：游走在小说与爆料之间 = 信披模糊地带。
3. **时序编排**：先发硬事实（公告/filing）锚定，再发软叙事放大。
4. **视觉包装**：IR / 路演式材料。
5. **跨境场域选择**：在监管更松的平台释放信息 = 跨市场消息管理。

反向信号（命中即警惕，非跟随）：
- 叙事与现金流是否脱节？
- 是否模糊信披边界？
- 是否用个人 IP 为某具体诉求背书？

## 用法提示
- 把任意事件套入上表，逐行填"该事件对应什么"。
- "一票否决条件"是核心：任何一行触发否决，则该阶段/整体不予推进。
- 输出时收敛为一句话纪律，例如："风险不可接受就空仓，不靠减仓化解；最大仓位面前交给独立规则否决。"
