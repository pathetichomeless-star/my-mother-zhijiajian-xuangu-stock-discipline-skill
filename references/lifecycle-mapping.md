# 投资流程透镜 · 标的生命周期六阶段映射（案例匿名化）

> 案例原型：2026 年一起公开的高净值人士情感与彩礼返还诉讼网络事件。本方仅作决策结构类比，人物一律化名，不对其事实主张作任何认定。

**角色设定**
- 投资人 A：叙事方，高净值公众人物、某加密货币创业者（社交平台活跃）。
- 标的 B：被长期关注/追求的公众人物（演员）。
- 竞品 / 旧关联方 C：B 的前任、某体育明星，曾与 B 公开绑定。

---

## ① 冷门期锁定标的（长期关注 = 屏保级自选）
A 在十多年前（约 2007）初见 B 的公开宣传照，将其长期保存在个人设备、视为"白月光"，直至多年后（约 2025）才真正接触。

**股市映射**：在标的无人问津时就建立**认知头寸（cognitive position）**——冷门期发现、长期跟踪，是顶级价值投资者的范本。
**陷阱**：A 存的是"别人包装好的人设照"，不是真实公司。股市里无数人在"人设/叙事"阶段就满仓，而非基本面。
**纪律**：watchlist 阶段要问"我理解这家公司吗"，不是"我喜欢这个故事吗"。

## ② 被竞品占据（C 的主升浪 = 场外等待）
B 与 C 绑定期间，A 完全无法入场——标的在别人手里、处在别人的主升浪。

**股市映射**：你看中的公司，股权被锁定 / 被巨头控股 / 正处别人持仓的主升浪，你只能场外等。
**纪律**：来晚了不硬挤。很多人亏在"别人主升浪末端去接盘"，就是没意识到自己来晚了。A 这步做对了——他等。

## ③ 解绑（分手 + 风波 = 困境反转）
B 与 C 分手，后 C 卷入负面风波，B 也被波及、声誉受损。标的"自由"了，但带着**隐性负债**。

**股市映射**：困境反转标的——旧庄走了，但伤口还在（商誉、诉讼、声誉、隐性负债）。
**纪律**：解绑 ≠ 便宜，更 ≠ 可买。先评估残留风险。解绑只是入场必要条件，不是充分条件。

## ④ 首次接触（试水建仓 = 祛魅）
约 2025 末，A 与 B 第一次真实接触。A 自述"忽然想不起来我等的是什么"——这就是**祛魅**。

**股市映射**：从"认知头寸"跨到"真实头寸"时，长期关注者往往买入即失望（预期差反转）。首次接触该是**试探性小仓**，用真金验证 thesis。
**纪律**：用真金小仓验证，别用多年幻想下重注。

## ⑤ 重仓 + 尾部闸门（全案核心）
- **前置对价（彩礼 ≈ 3000 万）** = 预付对价/保证金，打入对方账户。一旦转出即**沉没成本 + 对手已锁定**。股市类比：并购定金、定增预付款、或无退出机制的重仓成本基础。后来要靠诉讼追回——本质即"退出机制缺失的代价"。
- **尾部加价（洛杉矶 ≈ 5000 万）** = 在最大 commitment 前，对方突然加价；A 没凭感觉，而是把**全部现金跑给 AI 评估 → 拒绝**。这是框架里最教科书的一笔：在决策边界引入独立仲裁者做一票否决。
- **⚠️ 最大教训**：A 在 5000 万这种**极端尾部**用了闸门，却在 3000 万**前置对价**上没设防。说明**闸门必须用在"每一笔大钱"上，而非只在最后一步**。

## ⑥ 退出维权（起诉 + 长文 = 追偿 + 公开叙事）
证据：律师先发诉讼说明，A 随后发长文，**约 17 分钟精确间隔 = 编排好的组合拳**。

- 起诉 = 追偿/平仓（标的违约时启动合约追索）。
- 长文公开 = 把私密叙事公开化，等于**做空报告式舆论施压**。
- "先起诉再发文"时序 = 先用法律事实锚定，再用叙事放大。
**纪律**：退出要分清"追偿"与"叙事"。把私密细节公开是双刃剑——你一公开，对手与标的都会反应（反身性），且自己也被审判。股市里发公开做空报告，会引来对手反制、监管关注、自身头寸暴露。

---

## 收敛：三条硬纪律
1. **标的生命周期纪律**：锁定（冷门期建认知头寸）→ 等竞品解绑（不硬挤）→ 验残留风险（解绑≠便宜）→ 小仓试水祛魅 → 大钱前置对价必设退出机制 → 尾部加价交给独立闸门 → 退出分清追偿与叙事。
2. **闸门前置纪律**：风险闸门要用在**每一笔大钱**（含预付对价），不是只在最后一步。
3. **叙事反向纪律**：别人（尤其利益方）的公开长篇叙事，先当"诉求信号"而非"事实信号"处理。

---

## 附：A 的社交平台发文拆解（叙事工程）
A 的社交账号是**双轨叙事工程**，映射到股市清晰：

1. **人设维持（credibility arbitrage）**：同账号既发正经行业内容，又发私人长文，用"严肃创始人"身份为私人叙事背书。
2. **"虚构 + 实名"双轨**：长文标"纯属虚构"，却用真名 + 精确地点/天数，游走小说与爆料之间 = 信披模糊地带。
3. **发布时序编排**：先发诉讼事实（硬锚），再发文学（软放大）。
4. **视觉包装**：为自己与对方 P 封面图 = 漂亮 IR/路演材料。
5. **跨境场域选择**：在海外平台发（国内被封）= 选监管宽松场域释放信息。

**反向信号**：当"创始人/大股东突然在社交平台发长篇叙事"，先反向解读——①叙事与现金流是否脱节；②是否模糊信披边界；③是否用个人 IP 为某具体诉求背书。三条皆属"警惕"而非"跟随"。
